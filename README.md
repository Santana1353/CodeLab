# CodeLab – Práctica de Programación

CodeLab es un proyecto desarrollado con React que reúne una colección de ejercicios de programación basados en un documento original de C#. Su objetivo es convertir los ejercicios tradicionales en pequeñas aplicaciones interactivas donde se pueden probar diferentes soluciones y observar sus resultados.

## Características

- Colección de 30 ejercicios de programación.
- Cada ejercicio cuenta con su propia página.
- Enunciados basados en el documento original.
- Interfaces interactivas para ingresar datos y visualizar resultados.
- Buscador para encontrar ejercicios por número o nombre.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas

- **React:** desarrollo de interfaces de usuario.
- **JavaScript:** lógica y funcionalidad de las aplicaciones.
- **Vite:** herramienta de desarrollo y compilación.
- **CSS:** estilos y diseño visual.
- **React Router:** navegación entre las páginas.
- **Lucide React:** iconos de la interfaz.

## Requisitos

Para ejecutar el proyecto se necesita:

- Node.js
- npm
- Visual Studio Code (recomendado)

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Entrar en la carpeta del proyecto:

   ```bash
   cd CodeLab
   ```

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Iniciar el servidor de desarrollo:

   ```bash
   npm run dev
   ```

5. Abrir en el navegador la dirección que muestra la terminal, normalmente:

   ```text
   http://localhost:5173
   ```

## Propósito académico

Este proyecto busca poner en práctica los conocimientos de programación mediante la implementación de ejercicios que trabajan con operaciones matemáticas, estructuras de control, ciclos, condicionales, validación de datos y lógica de programación.

Además, permite experimentar con React y conocer cómo desarrollar aplicaciones web interactivas a partir de problemas de programación.
